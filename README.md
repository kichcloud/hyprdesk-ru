# hyprdesk с русским интерфейсом

Комплект для переноса перевода на другую машину.

| Файл | Что это |
| --- | --- |
| `hyprdesk-ru-locale.patch` | git-патч (один коммит) поверх upstream-коммита `0d59217` |
| `hyprdesk-ru-src.tar.zst` | полный снимок уже пропатченного дерева (git не нужен) |
| `hyprdesk-ru-update.sh` | обновление upstream с перебазированием перевода и пересборкой |
| `SHA256SUMS` | контрольные суммы |

Архив исходников (`hyprdesk-ru-src.tar.zst`) из-за размера приложен к релизу
этого репозитория, а не лежит в git. В папке на старой машине он рядом.

Патч добавляет русский каталог `locales/ru.toml` (4833 строки, весь интерфейс),
язык `ru` в i18n, пункт «Русский» в настройках и мастере первой настройки,
`--lang ru` в установщике, формат дат `ru_RU` и раскладку `ru` в мастере.

## Готовый клон (ветка `ru`)

В этом же репозитории есть ветка `ru`: полная история upstream, коммит
перевода и `hyprdesk-ru-update.sh`. Самый короткий путь на новой машине:

```bash
git clone https://github.com/kichcloud/hyprdesk-ru.git hyprdesk
cd hyprdesk
git checkout ru
./scripts/install.sh --from-source --lang ru --keyboard ru
```

Обновления:

```bash
git remote add upstream https://github.com/jacquesh82/hyprdesk
HYPRDESK_UPSTREAM=upstream/main ./hyprdesk-ru-update.sh
```

Ветка `main` — сам комплект (этот README, патч, релиз с архивом); при обычном
`git clone` открывается она, поэтому `git checkout ru` обязателен.

## Требования

- Arch, Debian/Ubuntu, Fedora или openSUSE; x86_64 или aarch64; systemd; `sudo`.
- Hyprland 0.57+ (поставить и зайти в сессию Hyprland до запуска hyprdesk).
- Интернет: установщик скачает зависимости, сборка — крейты Rust.
- ~4 ГиБ свободного места. Rust установщик поставит сам, если его нет.

## Вариант A: из git (рекомендуется)

```bash
git clone https://github.com/jacquesh82/hyprdesk
cd hyprdesk
git checkout -b ru 0d5921753c07b82c199bc0768cdb3ed7a839229e
git am /путь/до/hyprdesk-ru/hyprdesk-ru-locale.patch
./scripts/install.sh --from-source --lang ru --keyboard ru
```

- Перевод ложится **отдельным коммитом в ветке `ru`** — именно это защищает
  его от затирания при обновлениях (см. ниже).
- Если `git am` просит имя и почту (свежая система):
  `git -c user.name=you -c user.email=you@example.com am ...`
- `--from-source` обязателен: обычный `install.sh` ставит готовый пакет релиза,
  в нём русского перевода нет.
- `--keyboard ru` — раскладка ЙЦУКЕН; при необходимости `ru:winkeys` и т. п.
- Установщик по умолчанию ставит только рабочий стол; экран входа, LYRA и myMFA
  включаются флагами `--greeter`, `--lyra`, `--mymfa` или в мастере.

## Вариант B: из архива (без git)

```bash
tar --zstd -xf hyprdesk-ru-src.tar.zst
cd hyprdesk-ru
./scripts/install.sh --from-source --lang ru --keyboard ru
```

Архив — снимок без истории git: он удобен для установки без сети/без git, но
для обновлений с сохранением перевода нужен вариант A (клон + ветка `ru`).

Если `tar` не понимает `--zstd`:

```bash
zstd -d < hyprdesk-ru-src.tar.zst | tar -x
```

## После установки

- Проверить: `hyprdesk config get language` → `ru`.
- Переключить вручную: Настройки → Рабочий стол → Язык → «Русский»
  или `hyprdesk config set language ru`.
- Разово, без записи в конфиг: `HYPRDESK_LANG=ru hyprdesk ...` (для CLI-команд).
- `language = "auto"` определяет язык по системной локали
  (`LC_ALL`, затем `LC_MESSAGES`, затем `LANG`).

## Обновления без потери перевода

Перевод вкомпилирован в бинарник (`include_str!`), поэтому «положить
`ru.toml` рядом с релизным бинарником» не сработает: в релизном бинарнике нет
самого языка `ru`. Сохранить перевод можно только собирая hyprdesk из
пропатченного дерева. Что при этом уже защищает перевод:

- установка из исходников кладёт бинарник в `~/.local/bin/hyprdesk`, а не в
  `/usr/bin`; системный `pacman -Syu` (и кнопка обновлений в панели) этот файл
  не трогает;
- `scripts/update.sh` тянет upstream только `git pull --ff-only`; при наличии
  локального коммита `ru` fast-forward невозможен — обновлятор останавливается
  и **ничего не перезаписывает**.

То есть «затирание» исключено, но и обновление само не приедет. Чтобы
обновляться, перебазируйте перевод на свежий upstream и пересоберите:

```bash
cd hyprdesk
/path/to/hyprdesk-ru/hyprdesk-ru-update.sh
```

Если `origin` — ваш форк, добавьте upstream и укажите его:
`git remote add upstream https://github.com/jacquesh82/hyprdesk` и
`HYPRDESK_UPSTREAM=upstream/main ./hyprdesk-ru-update.sh`.

Скрипт делает `git fetch`, `git rebase origin/main`, проверяет каталог
(`locales/ru.toml` покрывает все ключи, плейсхолдеры совпадают) и запускает
`./scripts/install.sh --from-source --lang ru`. Перевод остаётся верхним
коммитом, upstream-изменения подтягиваются.

- Конфликт при rebase — скрипт остановится и покажет, что делать
  (`git add -A && git rebase --continue`, затем запустить снова).
  Для повторяющихся конфликтов включён `git rerere`.
- Upstream добавил строки — скрипт перечислит ключи без перевода и всё равно
  соберёт: новые строки временно покажутся по-французски. Переводы допишите в
  `locales/ru.toml` и закоммитьте в ветку `ru`.
- Пользуетесь экраном входа hyprdesk — после сборки выполните
  `./scripts/update.sh --yes`: он обновит root-копию бинарника для greetd.

Обновлять «официальным» `scripts/update.sh` без перебазирования не нужно: он
либо остановится на `git pull --ff-only`, либо (если перевод не закоммичен, а
лежит правками в рабочем дереве) пересоберёт локальное дерево — но тогда
upstream-коммиты не подтянутся.

### Самый надёжный вариант — влить перевод в upstream

Если отправить патч в upstream (PR), после принятия русский язык будет в
официальных релизах, и обычные обновления будут его сохранять сами. До этого
момента локальная ветка `ru` + скрипт выше — рабочая схема.

## Ограничения

- Голосовые модели (Piper/Vosk) в hyprdesk только `fr`/`en`: голосовое
  управление LYRA по-русски не работает. Текстовый чат работает.
- Собственный интерфейс LYRA — отдельный репозиторий, там по-прежнему только
  `fr`/`en`; hyprdesk передаёт ей английский язык и просит отвечать по-русски.
- Сообщения bash-установщика и комментарии в генерируемом
  `~/.config/hypr/hyprdesk.lua` остаются французскими/английскими.
- Перевод стоит вычитать носителю, особенно термины (панель, док, лаунчер…).

## Перенос настроек с текущей машины (необязательно)

```bash
hyprdesk export ~/hyprdesk-setup.tar.gz    # на старой машине
hyprdesk import ~/hyprdesk-setup.tar.gz    # на новой
```

Импорт переносит тему, обои, виджеты, панель и настройки, включая язык;
экраны и пути к приложениям могут отличаться.
